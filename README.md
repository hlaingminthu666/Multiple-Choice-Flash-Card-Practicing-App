# 🎯 Multiple Choice Flash Cards · V2.2

မြန်မာ ကျောင်းသားတွေအတွက် **ရွေးချယ်ဖြေဆိုရတဲ့ (Multiple Choice) လေ့ကျင့်ခန်း App** ပါ။ ဆရာက CSV / Excel file တင်ပေးရုံနဲ့ ကလေးတွေက ဖုန်း၊ tablet၊ PC ပေါ်မှာ ချက်ချင်း လေ့ကျင့်လို့ရပါတယ်။ Internet မရှိလည်း အလုပ်လုပ်ပါတယ် (PWA)။

## ✨ V2.2 မှာ ပါလာတာတွေ
- 🔊 **Audio Player:** Play / Pause · ⏪ 5 စက္ကန့် နောက်ပြန် · 🔁 Loop One · Speed `0.5× 0.75× 1× 1.25× 1.5×` · ဆွဲရွှေ့လို့ရတဲ့ progress bar
- ⏱ **Start / End:** အသံ file ရှည်တစ်ခုထဲက လိုတဲ့အပိုင်းကိုပဲ ဖွင့်လို့ရပါတယ်
- ⚡ **Auto-play:** မေးခွန်းပေါ်တာနဲ့ အသံ အလိုလိုဖွင့်ပါတယ် (အဖွင့်/အပိတ် ရွေးလို့ရ)
- 🎧 **အသံသီးသန့် မေးခွန်း:** မေးခွန်းစာ မပါဘဲ "နားထောင်ပြီး ရွေး" လို့ရပါတယ်
- Audio file ကို upload လုပ်ထားမှသာ Player ပေါ်ပါတယ်။ File မတွေ့ရင် သတိပေးပါတယ်
- ⌨️ ကီးဘုတ်: `Space` ဖွင့်/ရပ် · `←` 5 စက္ကန့် နောက်ပြန်

**V2.2 မှာ ပြင်ထားတဲ့ Bug တွေ**
- ပုံမဟုတ်တဲ့ file (ဥပမာ mp3) ကို မေးခွန်း file လို့ မှားဖတ်တာ
- ပုံနဲ့ အသံ file နာမည်တူရင် (`cat.jpg` / `cat.mp3`) ပုံနေရာမှာ အသံ ရောသွားတာ
- ဖုန်းထဲ နေရာမလောက်လို့ မသိမ်းနိုင်တာကို အသံတိတ် ကျော်သွားတာ (အခု သတိပေးစာ ပြပါတယ်)
- Next နှိပ်ပြီးတာတောင် အသံဟောင်း ဆက်မြည်နေတာ · အဖြေရွေးလိုက်ရင် အသံ ခဏရပ်ပေးပါတယ်
- `.tsv` / `.ods` file တွေကိုလည်း ဖတ်လို့ရပါပြီ

## 📄 CSV / Excel Format
`templates/` folder ထဲမှာ နမူနာ **mc-template-v2-2.csv** နဲ့ **mc-template-v2-2.xlsx** ပါပါတယ်။

| Column | လိုအပ်လား | ရေးနည်း | ဥပမာ |
|---|---|---|---|
| **Questions** | ✅ (ပုံ/အသံ ပါရင် ဗလာထားလို့ရ) | ကွက်လပ်ကို `___` (underscore ၃ ခုနဲ့အထက်) | `မြို့တော်မှာ ___ ဖြစ်သည်။` |
| Image | မထည့်လည်းရ | ပုံ file နာမည် | `bell.jpg` |
| Audio | မထည့်လည်းရ | အသံ file နာမည် (mp3 · m4a · wav · ogg) | `lesson1.mp3` |
| Start | မထည့်လည်းရ | စဖွင့်ချိန် · ဗလာ = အစကနေ | `0:12` (သို့) `12` |
| End | မထည့်လည်းရ | ရပ်ချိန် · ဗလာ = အဆုံးထိ | `1:05` |
| **Options** | ✅ | ရွေးစရာ ၂–၁၀ ခု, `\|` နဲ့ ခွဲပါ | `ရန်ကုန်\|မန္တလေး\|နေပြည်တော်` |
| **Answer** | ✅ | အဖြေစာသား (သို့) A–J / 1–10 / က–ည | `နေပြည်တော်` · `B` · `2` · `ခ` |
| Explanation | မထည့်လည်းရ | အဖြေရွေးပြီးမှ ပေါ်ပါမယ် | |

**နမူနာ (CSV)**
```csv
Questions,Image,Audio,Start,End,Options,Answer,Explanation
Listen and choose the word you hear.,,lesson1.mp3,0:00,0:06,apple|orange|banana,orange,
Listen again. What colour is the bag?,,lesson1.mp3,0:06,0:14,red|blue|green,B,
,,bird.mp3,,,ငှက်|ကြောင်|ခွေး,ငှက်,
"$\frac{1}{2} + \frac{1}{4}$ = ___",,,,,"$\frac{3}{4}$|$\frac{2}{6}$|$\frac{1}{6}$",A,
```

**သတိထားရန်**
- CSV ကို Excel မှာ **"CSV UTF-8"** နဲ့ save ပါ (မဟုတ်ရင် မြန်မာစာ `????` ဖြစ်ပါမယ်)။ `.xlsx` ကို တိုက်ရိုက် တင်တာ ပိုစိတ်ချရပါတယ်။
- Excel မှာ Start / End column ကို **Text** format ထားပါ (နမူနာ .xlsx မှာ ထားပြီးသား)။
- ရွေးစရာ ခွဲတဲ့အခါ `|` ကို အမြဲသုံးပါ (`,` သုံးရင် `1,000` လို ဂဏန်းတွေ ကွဲသွားနိုင်ပါတယ်)။
- သင်္ချာကို `$` နှစ်ခုကြားမှာ ရေးပါ: `$\frac{1}{2}$` `$x^2$` `$\sqrt{16}$` `$90^\circ$` `$3 \times 4$` · ငွေ $ ကို `\$` လို့ ရေးပါ။

## 📦 File တင်နည်း (App ထဲမှာ)
1. **File တင်** ကို နှိပ်ပါ
2. CSV/Excel နဲ့ ပုံ၊ အသံ file အားလုံးကို **တစ်ခါတည်း ရွေးပါ** · ဒါမှမဟုတ် အကုန်လုံးကို **.zip တစ်ခုထဲ** ထည့်ပြီး zip ကိုပဲ ရွေးပါ
3. File တွေကို ဖုန်းထဲမှာ သိမ်းထားလို့ နောက်တစ်ခါ ဖွင့်ရင် ပြန်တင်စရာ မလိုပါဘူး (offline လည်း ရပါတယ်)

💡 အသံ file ကို **mp3 · 64 kbps · mono** နဲ့ ချုံ့ထားရင် မေးခွန်း ၁၀၀ လောက်ထိ ဖုန်းထဲ အေးဆေး ဆံ့ပါတယ်။ ပုံ/အသံ file တွေကို GitHub ပေါ် တင်စရာ မလိုပါဘူး။

## 🚀 GitHub Pages ပေါ် Update တင်နည်း
1. Repo ထဲက `index.html`, `sw.js`, `manifest.webmanifest`, `icons/` ကို ဒီ file အသစ်တွေနဲ့ အစားထိုးပါ (`templates/`, `README.md` ကိုလည်း ထည့်ပါ)
2. Commit → ၁–၂ မိနစ် စောင့်ပါ
3. ဖုန်းမှာ App ကို ဖွင့်ရင် V2.2 ကို အလိုအလျောက် ပြောင်းပြီး ပြန်ဖွင့်ပေးပါမယ်

> ⚠️ နောက် version တင်တိုင်း `sw.js` ထိပ်က `const VERSION = "2.2.0";` ကို **မဖြစ်မနေ ပြောင်းပါ** (ဥပမာ `"2.3.0"`)။

**App ထည့်နည်း:** Android / PC Chrome မှာ **App ထည့်မယ်** ခလုတ်ကို နှိပ်ပါ · iPhone / iPad Safari မှာ Share → **Add to Home Screen** ကို နှိပ်ပါ။
