# Multiple Choice Flash Cards V2.1 (PWA)

## GitHub ပေါ် Update တင်နည်း
1. Repo ထဲက V2.0 `index.html` ကို ဒီ `index.html` နဲ့ အစားထိုးပါ။
2. `sw.js`, `manifest.webmanifest`, `icons/` folder ကို repo အမြစ် (index.html ဘေး) မှာ ထည့်ပါ။
3. Commit လုပ်ပြီး GitHub Pages ၁-၂ မိနစ် စောင့်ပါ။
4. ဖုန်း/PC မှာ App ကို တစ်ခါဖွင့်ရင် V2.1 ကို အလိုအလျောက် ပြောင်းပြီး offline cache ထဲ သိမ်းပါမယ်။

## နောက်ထပ် Version တင်တိုင်း
- `sw.js` ထိပ်က `const VERSION = "2.1.0";` ကို အသစ်ပြောင်းပါ (ဥပမာ "2.2.0")။ မပြောင်းရင် ဖုန်းတွေက version အဟောင်းကို ဆက်သုံးနေနိုင်ပါတယ်။
- V2.0 မှာ sw file နာမည် တခြား (ဥပမာ service-worker.js) ဖြစ်ခဲ့ရင် အဲဒီ file ကိုလည်း ဒီ sw.js အတိုင်း content ထည့်ထားပါ (သို့) ဖျက်ပါ။
