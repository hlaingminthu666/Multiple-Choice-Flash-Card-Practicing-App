# Multiple-Choice-Flash-Card-Practicing-App
📚 Offline multiple-choice flash card app for students &amp; teachers. Upload lessons as CSV, Excel or ZIP (with pictures) and practise 2–10 option questions. English / မြန်မာ UI, explanations, shuffle, retry missed cards. Installable PWA, no sign-up, works on phone, tablet &amp; PC.

Turn any lesson into multiple-choice flash cards. Teachers write questions in Excel,
students practise on any device, even without internet.

- 📂 Upload **.csv / .xlsx / .zip** (pictures in questions *and* answers)
- 🔟 **2–10 options** per question (A–J / က–ည, keyboard 1–9, 0)
- 🌐 **English / မြန်မာ** switch
- 💡 Optional explanations after each answer
- 🔀 Shuffle, 🔁 retry only the missed cards, 🎉 sounds & mascot
- 📲 Installable **PWA**, fully offline after first visit

> Your files never leave your device. Everything is stored locally in the browser.
